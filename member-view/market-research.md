# Market Research: Employee Self-Service Portals

## Overview

This document analyzes popular HR management and employee self-service (ESS) applications to understand what features members (non-admin employees) typically expect from a workload management system.

---

## Key Players in the Market

### 1. BambooHR
**Focus:** HR Management with strong employee self-service

**Member Features:**
- Personal profile management (contact info, emergency contacts)
- Time-off requests and balance tracking
- Timesheet entry and submission
- Benefits enrollment and viewing
- Access to company directory
- Goal tracking and performance reviews
- Training program access

### 2. Asana / Monday.com / ClickUp
**Focus:** Task and Project Management

**Member Features:**
- "My Tasks" view - all assigned tasks in one place
- Task status updates (To Do → In Progress → Done)
- Time tracking per task
- Due date visibility and notifications
- Comments and collaboration on tasks
- Personal productivity dashboards
- Workload visualization

### 3. Gusto / Rippling
**Focus:** Payroll and HR

**Member Features:**
- Pay stub access
- Tax document downloads (W-2, etc.)
- Benefits management
- Time-off requests
- Personal information updates
- Direct deposit setup
- Company policy documents

### 4. Microsoft Planner / Teams
**Focus:** Enterprise Collaboration

**Member Features:**
- "Assigned to Me" task view
- Task progress tracking
- Date and priority visibility
- Charts showing task distribution
- Integration with calendar

### 5. Factorial HR / PeopleHR
**Focus:** SMB HR Solutions

**Member Features:**
- Leave management (request, view balance, see team calendar)
- Document signing
- Shift scheduling view
- Time tracking
- Performance reviews
- Company announcements

## User Experience Patterns

### Dashboard Design
Most successful apps use a **card-based dashboard** showing:
1. Quick stats (active tasks, pending approvals)
2. Today's tasks or priorities
3. Upcoming deadlines
4. Recent notifications

### Navigation Patterns
Common sidebar/navigation items for members:
```
📊 Dashboard
📋 My Tasks
📅 Calendar
🏖️ Leave/Time-Off
⏱️ Timesheets
📄 Documents
⚙️ Settings
```

### Interaction Patterns
- **Quick Actions:** Mark complete, request leave should be 1-2 clicks
- **Inline Editing:** Status changes directly from task lists
- **Mobile-First:** Essential actions work on mobile

---

## Key Insights

### What Members Value Most
1. **Clarity** - Knowing exactly what's assigned to them
2. **Autonomy** - Self-service without admin involvement
3. **Transparency** - Seeing where requests stand (pending/approved)
4. **Simplicity** - Quick actions, minimal friction

### Common Pain Points Members Face
1. Not knowing task priorities
2. Unclear approval status for requests
3. Difficulty tracking time spent
4. No visibility into team workload
5. Cumbersome processes for simple actions

### Mobile vs Desktop Usage
- 60% of leave requests happen on mobile
- 80% of detailed task work happens on desktop
- Notifications are primarily consumed on mobile
