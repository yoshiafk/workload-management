# Member View Research

This folder contains comprehensive research on what team members (non-admin users) should see and be able to do in a workload/HR management application.

## Contents

1. **[market-research.md](./market-research.md)** - Analysis of similar applications in the market
2. **[feature-requirements.md](./feature-requirements.md)** - Detailed feature requirements from member's perspective
3. **[current-state-analysis.md](./current-state-analysis.md)** - Analysis of what's currently implemented
4. **[proposed-features.md](./proposed-features.md)** - Proposed new features and enhancements

## Quick Summary

### Current State
The application already has a `MemberDashboard` that shows:
- Active tasks assigned to the member
- Upcoming tasks
- Workload percentage
- Task completion stats

### Key Missing Features (Priority Order)
1. **Leave Management** - Request and track leave/time-off
2. **Task Progress Updates** - Mark tasks as in-progress/complete
3. **Timesheet Submission** - Log hours worked per task
4. **Personal Profile Management** - Update personal information
5. **Team Calendar View** - See team availability and who's on leave
6. **Document Access** - View HR policies and personal documents
