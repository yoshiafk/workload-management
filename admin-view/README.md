## Quick Summary

### Current State
The admin dashboard (`WorkloadSummary`) already includes:
- Team capacity heatmap
- Workload utilization charts
- Distribution analytics (complexity, category)
- Cost projections
- Resource allocation management

### Key Missing Features (Priority Order)
1. **Leave Approval Queue** - Review and approve/reject leave requests
2. **Timesheet Review** - Approve submitted timesheets
3. **Task Status Monitoring** - Track member task progress
4. **Team Calendar** - View who's on leave when
5. **Notification Management** - Send alerts to team members
6. **Leave Balance Administration** - Set/adjust leave entitlements
